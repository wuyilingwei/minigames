# 调研与决策

- [共鸣增益边界] -> 用户提出“共鸣会对其他效果 +50% 增益” -> 本轮将“其他效果”限定为火、水、草、雷元素套装效果，避免基础攻击、生命、职业与祝福被无差别放大；界面明确写成“其他元素套装效果 +50%”。
- [共鸣防御反馈] -> 当前仅在伤害公式中静默加入 12% 减伤 -> 需要在实际受击日志显示共鸣减免的伤害值和来源，不能只在元素详情弹窗说明。
- [敌人头像现状] -> 当前敌人只按 slime/undead/beast/caster/default 五类共用模板 -> 需要基于敌人本体名生成稳定且可辨识的轮廓、颜色与特征组合，同名敌人跨刷新保持一致。
- [穿戴互斥现状] -> 斗篷和披风被推断为 `body`，与铠甲争用身体槽；靴子、手套等还可能回退为武器 -> 应将外层穿戴与饰品归入可共存的附加槽规则，身体槽只承担核心护甲。
- [高难金币] -> 当前胜利金币没有难度效率奖励 -> 增加从难度 1 起递增的金币倍率，并在难度面板和胜利结算中显示实际倍率。
- [火套倍率审查] -> 子分支首稿把 `1.25` 整体乘以 `1.5` -> 会把 +25% 错误变成 +87.5%；已要求只把额外加成乘 1.5，即火四件最终为 +37.5%。
- [减伤叠加审查] -> 子分支首稿把原本加算的共鸣减伤改成乘算 -> 会静默改变 8.0 已交付的减伤语义；已要求保留总减伤加算，只用有/无共鸣的结果差显示具体减免。
- [附加穿戴方案] -> 新增 `outerwear` 并由第五“附加”槽接受 -> 铠甲继续留在身体槽，斗篷/披风/靴子等可与护甲共存；旧 `body`/`oneHand` 错分存档按名称迁移，低难未开第五槽时不生成附加穿戴。
- [头像差异方案] -> 仅按五类共享模板不足以满足要求 -> 敌方头像改为完整名称的确定性哈希，组合颜色、轮廓、角/耳/翼/触手与眼睛，同名稳定且不同名称可辨。

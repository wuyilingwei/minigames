# 任务计划

## 目标

保留设置页“自动选择装备”，修复设置页两个自动开关的实际行为；让设置页复选项统一使用现有像素滑动开关样式，并让自动选择完整处理无正收益掉落。

## 范围

- 设置页保留自动选择装备，并与战利品弹窗入口同步。
- CRT 扫描线、战斗反馈动画、事件默认收起和自动战斗统一使用像素滑动开关。
- 战利品弹窗中的自动选择仍默认关闭，并维持 5 秒自动结算与约 1 秒时闪烁推荐边框的行为。
- 自动选择遇到正收益时装备最优项，零收益或负收益时自动放弃，不要求玩家介入。
- 自动战斗开关应可靠启停后续回合，避免暂停设置期间遗留的计时回调继续执行。
- 更新自动化测试并完成本地、浏览器及线上验证。

## 步骤

1. 记录当前设置入口与开关样式的实现位置。
2. 调整设置页标记和相关同步逻辑。
3. 更新测试契约并运行完整检查。
4. 在浏览器验证设置页与战利品弹窗。
5. 发布、线上复验并完成 Git 交付。

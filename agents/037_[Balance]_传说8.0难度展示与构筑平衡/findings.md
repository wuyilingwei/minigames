# 调研记录

- [应急盾] 当前固定使用 100/75/50/25，难度 6+ 的玩家与敌人属性已经按倍率成长。 -> [结论] 使用与玩家基础属性相同的 `1.18^难度` 缩放并取整，保留四次相对衰减关系。
- [难度说明] 当前累计规则被拼成一段分号文本，难度 10 时难以扫读。 -> [结论] 使用默认关闭的 `details` 单条栏；摘要展示当前难度已获得的全部规则标签，展开后逐条显示完整说明。
- [装备阶级] `affixTier` 已有 0/1/2/3 四档，但 UI 只在非零时显示“词条阶 N”。 -> [结论] 四档统一命名为“制式 / 精工 / 秘藏 / 神铸”，卡片始终显示等阶。
- [追踪与闪避] 非隐士基础闪避仅 3%~5%，装备闪避可以掷出 0%，难度 10 第一波追踪已达约 12%。 -> [结论] 提高四职业基础闪避并为随机装备提供正向闪避下限，避免追踪让大多数早期构筑的闪避恒为零。
- [初始装备] 四件初始装备均为零属性。 -> [结论] 每件至少提供一项小额基础属性，不改变其无元素、无词条定位。
- [像素角色] 我方像素只按宽泛 `unitKind` 生成，四职业没有稳定独立轮廓。 -> [结论] 将职业名映射为四套显著不同的头饰、配色和武器轮廓，并保持多友军适配。
- [文案] 应急盾当前同时显示槽位“附加”和部位“附加”。 -> [结论] 高难槽显示为“高难”，应急盾卡不再重复显示“附加”部位字样。
- [治疗澄清] 用户给出难度 3–10 精确衰减表 95/90/85/75/70/65/55/50%，并明确最高难度只能恢复受伤血量的 50%。 -> [结论] 上限基数使用治疗前的缺失生命，不再使用最大生命；难度 0–2 不限制。
- [对抗性复审] 实际治疗已限幅，但自动战斗决策与 Boss 快速模拟仍按未受限回血估算。 -> [结论] 两条估算路径也必须调用同一缺失生命上限，避免高难生存判断虚高。
- [等阶反馈] 子任务只在掉落装备卡显示四阶名称，HUD 槽位仍只显示部位。 -> [结论] 普通装备 HUD 同时显示“部位 · 等阶”；应急盾仍隐藏“附加”，装备卡仅显示其等阶。
- [折叠默认态] 原生 `details` 初始关闭，但用户再次打开面板时可能保留上次展开状态。 -> [结论] 每次进入难度面板都主动设为关闭，并让摘要标签直接携带金币、回血、盾值与装备等阶信息。
- [浏览器验收] 难度 10 摘要默认收起并显示金币 +100%、回血 50%、精工/秘藏/神铸、高难盾 523 等累计标签；展开显示 523/392/261/130，关闭重开后再次收起。 -> [结论] 单条摘要、累计标签和默认态符合需求。
- [浏览器验收] 战士初始闪避 12% 加两件初始装备共 4%，在第一波约 12% 追踪下仍有正有效闪避；HUD 四件制式装备显示各自属性，高难盾无“附加”字样。 -> [结论] 追踪平衡与初始装备反馈有效。
- [浏览器验收] 四次真实新局分别渲染了“像素单位：战士 / 天使 / 勇者 / 隐士”，自动化输出与 SVG 专项测试确认四套 markup 两两不同。 -> [结论] 四职业差异化路径已贯穿实际战斗卡。

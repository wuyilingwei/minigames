# 调研记录

- [推荐标记] -> `classifyRecommendation()` 对任何微小正收益都会进入“谨慎选择”分支 -> 应在该分支前识别输出与生存绝对变化均小于 0.5% 的情况并返回“普通”。
- [自动选择边界] -> 自动动作必须依赖用户主动勾选，且掉落弹窗存在收起、放弃、手动选择和满槽替换流程 -> 计时器需在所有离开当前推荐卡的路径中取消，不能跨弹窗或跨掉落触发。
- [持久偏好] -> 仅在当前弹窗勾选一次并不能减少后续操作 -> 将 `autoLootSelect` 加入既有本地 preferences，旧数据缺字段时默认关闭，用户主动取消后持续保持关闭。
- [浏览器检查] -> 页面隔离执行环境无法直接调用游戏作用域的 `classifyRecommendation()`，刷新后一次 locator 属性读取也超时 -> 采用隔离回归断言验证“普通”阈值顺序，并以可见 DOM、复选框属性和完整交互流程验证自动选择，没有修改浏览器存储进行造数。

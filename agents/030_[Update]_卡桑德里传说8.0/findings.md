# 调研与决策

- [现有架构] -> 检查 `games/cassandri-legend/index.html` -> 游戏是单文件 HTML/CSS/JS；装备、战斗、存档和 UI 高耦合，需以独立 worktree 分区修改后再统一合并。
- [兼容边界] -> 检查 7.0 与存档任务 -> 自动战斗和自动选装必须继续独立且默认关闭；档案仍覆盖永久成长、自动档与三个手动槽，8.0 新字段必须能从旧存档规范化补齐。
- [既有盾语义] -> 检查当前运行时 -> `player.ZDYHP` 是装备进入战斗时给予的生命护盾，敌方也有单一 `shield` 数值；8.0 需显式拆为次数盾、临时盾、持续盾，并在 UI/日志中区分。
- [装备槽兼容] -> 检查商城逻辑 -> 现有 `slot5Unlocked` 是永久第五槽；难度 6 后的额外容量不能重复叠加成隐含第六槽，需统一由容量计算函数裁决并保留商城购买价值。
- [表现现状] -> 检查战斗区 -> 当前头像仅为字符占位；8.0 应用 CSS/HTML 像素结构绘制敌我小人，避免引入与单文件发布不匹配的外部图片依赖。
- [战斗分支首轮实现] -> 只读检查 worktree diff -> 多段结算初稿通过重命名保留了未调用的完整旧 `enemyAttackLegacy`，新路径同时漏掉侵蚀、持续伤害、偷窃中断、反伤和复活等既有行为；已要求改为 helper 化的单一新实现并覆盖每段属性触发。
- [高难回血语义] -> 检查首轮 `healPlayer` -> 不能把“单次恢复量至多 60%”错误实现成“高难生命值永远不能超过 60%”，四色加成也不能突破单次 60% 上限；已要求按恢复量衰减并保留多次治疗逐步回满的能力。
- [像素分支首轮实现] -> 只读检查 worktree diff -> roster 与内联像素 SVG 方向可行，但代码注释包含版本任务标记且攻击动画尚未见实际调用；已要求清理注释并打通反馈接口。
- [像素运行时约束] -> 首次内联脚本语法检查受 shell 转义影响 -> 改用 heredoc 只读检查后通过；后续不要复用易破坏正则的内联命令。
- [像素接口] -> 保留 `player` / `enemy` 单例和旧战斗 DOM ID -> roster adapter 优先读取 `player.allies`、`enemy.enemies`，再回退到 roster 或单例，额外单位不占用旧 ID。
- [装备数据模型] -> 检查匿名槽位与掉落替换 -> 保留数组存档形状，固定索引为头部/身体/主手/副手/饰品；商城永久解锁与难度 6 奖励共用第五槽，最大容量为 5。
- [合法换装] -> 将装备候选投影为完整 slots 结果 -> 双手主手会卸下副手，盾或副手单手会卸下冲突双手；手动替换、推荐与自动选择必须复用同一 `buildEquipAction`。
- [装备分支验证缺口] -> 审查已提交源码 -> 静态构建仅复制 HTML，未解析内联脚本，因此遗漏 `shieldGain` 生成分支的括号语法错误；低难还可能掉落未开放槽位的饰品并让推荐得到空比较。集成层需补脚本解析与无合法候选行为测试。
- [恢复规则] -> 统一 `healPlayer` 主路径 -> 难度 3 的单次/战后恢复量上限为最大生命 60%，每级下降 2%，难度 10 为 46%；四色共鸣先将恢复量提高 20%，最终仍受该单次上限约束。
- [护盾兼容] -> `normalizeCombatant` 归一化旧 `ZDYHP` / `enemy.shield` -> 旧单值进入持续盾，伤害按次数盾、临时盾、持续盾顺序结算并回写旧字段。
- [战斗分支遗留] -> 审查提交与子 agent 明示 -> 新多段函数尚未完整移植旧敌方效果，且遗留未调用的 `enemyAttackLegacy`；集成层必须在交付前收敛为单一行为实现并增加逐段触发测试。
- [单文件复杂度] -> 用户追加拆分要求 -> 本次采用无构建器的最小端到端拆分：`index.html` 只留结构，样式移入 `styles.css`，运行时移入 `game.js`；先稳定资源边界，避免在同一版本同时引入 ES module/global API 大迁移。
- [装备换装回血绕过] -> 检查 `applyEquipStats` -> 旧逻辑每次重算装备都会把当前生命设为新上限，等于在高难免费回满；已改为首次建角回满、后续仅补新增生命上限并保留已有损血。
- [多段伤害平衡] -> 对比旧单段伤害与初稿全额多段 -> 每回合总攻击预算按段数温和提升 12%，再均分到各段；二段总量约 1.12 倍、三段约 1.24 倍、四段约 1.36 倍，同时每段独立判定闪避、暴击、弱化、诅咒、吸血、剧毒、护盾与反伤。
- [战斗单一路径] -> 重构旧/新敌攻函数 -> 移除 `enemyAttackLegacy`，以 `resolveEnemyAttackSegment` + `settleEnemyTurn` 保留侵蚀、再生、净化回退、战狂、小偷、防盗与复活行为。

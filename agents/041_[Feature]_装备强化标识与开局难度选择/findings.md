# 调研记录

- [装备语义] -> `affixTier` 已由难度 3/6/9 决定，但界面只显示制式、精工、秘藏、神铸 -> 保留名称并追加独立强化标识，文案统一称“强化等级”，不引入随机品质概念。
- [开局顺序] -> 欢迎页按钮当前直接调用 `startGame()`，而难度 3+ 的职业与祝福禁用也在该函数内生成 -> 难度必须在 `startGame()` 之前确认，否则禁用规则可能依据旧难度计算。
- [难度弹窗] -> 普通查看模式会在当前值未变化时禁用确认按钮 -> 新冒险门禁必须允许确认当前难度，并在关闭时安全返回欢迎页。
- [跨模块测试] -> 强化标识实现后，旧难度标签测试仍硬编码“精工装备/秘藏装备/神铸装备” -> 集成阶段需将其改为新的强化等级标签，并继续覆盖累计门槛。

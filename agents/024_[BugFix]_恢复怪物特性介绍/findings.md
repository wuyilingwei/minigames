# 调查记录

- [特性数量检查] -> 当前版本与原始 7.0 均包含 18 个相同 ID -> 没有丢失怪物特性机制。
- [战斗 UI 检查] -> 原始 7.0 显示“名称＋说明”，当前版本仅显示名称 -> 战斗卡片的说明文本在整合时丢失。
- [说明内容检查] -> 当前“虚弱”“诅咒”描述缺少 3–5% 和 1–3% -> 实际战斗计算仍使用对应范围，仅文案不完整。
- [线上复现] -> 终端显示“诅咒：攻击命中后降低玩家暴击率”，战斗卡片只显示“【诅咒】” -> 与源码差异一致。
- [首次内联脚本检查] -> `node -e` 中正则转义过度导致 `Unterminated regexp literal` -> 改为按 `<script>`/`</script>` 索引提取后语法检查通过，游戏代码无语法错误。
- [移动视口自动化] -> 浏览器接口不提供 `setViewportSize` -> 以现有移动媒体规则、可换行 CSS 契约和桌面实战截图验证，未切换到其他浏览器工具。

# 调研记录

- [现状] `slot5Unlocked` 与难度 6 共用第五槽，商城购买和难度解锁无法同时提供不同槽位。 -> [结论] 保留字段作为旧存档来源，但将其语义迁移为独立购买槽解锁。
- [现状] 第五槽接受 `accessory/outerwear`，所有装备统一保存在 `player.slots`。 -> [结论] 新增第六购买槽及专用 `purchase` 部位，避免职业护符与普通附加装备互相占位。
- [需求解释] “职业效果 +25%”按职业本体效果计算，不放大祝福；应急护盾按每次进战触发并从 100 依次衰减至 25，第四次后损坏。
- [用户澄清] 高难附加装备属于高难槽，相当于额外初始装备。 -> [结论] 应急护盾不进入普通掉落池；达到门槛的新征途直接把它装入高难槽，购买槽则只接受商城来源装备。
- [兼容约束] 旧档只有 4/5 槽，且现有 `slot5Unlocked` 可能来自商城。 -> [结论] 归一化必须按槽位接受类型重排，不能截断或误删已有第五槽装备。

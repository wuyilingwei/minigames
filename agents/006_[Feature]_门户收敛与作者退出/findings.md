# 调研记录

- [首页表现偏张扬] -> 当前门户使用大尺寸标题、渐变氛围光与高对比彩色卡片 -> 改为中性色调、较小字级和低动效卡片，保留清晰的可游玩入口。
- [作品署名] -> 《卡桑德里传说》由用户指定主创为槃清、编码归本站作者；《十光年的距离》在游戏内已有创作信息 -> 门户分别展示明确署名与“创作者信息详见游戏内”。
- [“九光年”称呼] -> 已收录的目录、路径与游戏标题均为《十光年的距离》 -> 保持既有作品名称和 URL，不做无依据重命名。
- [退出行为] -> 静态游戏无法安全关闭用户浏览器标签页 -> 使用固定的“退出游戏”链接返回门户根目录，不触碰游戏逻辑或本地存档。

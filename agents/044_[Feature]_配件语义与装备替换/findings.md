# 调研记录

- [重复高难语义] -> 第五槽显示“高难”，物品显示“高难应急护盾”，日志与商城仍有“高难槽” -> 槽位统一为“配件”，物品统一为“应急护盾”，难度只负责解锁与数值。
- [旧存档兼容] -> `emergencyShield` 目前持久化为 `outerwear` 且旧名称会直接保留 -> 继续使用稳定 ID，在归一化时迁移为 `accessory` 并刷新显示名称。
- [替换路径] -> `equipToSlot()` 在发现无冲突空位时立即自动穿戴，只有没有空位才显示替换选择 -> 改为始终显示全部合法位置，由玩家决定替换或使用空位。
- [冲突边界] -> 槽位允许为空，`buildEquipAction()` 只在手持组合上自动卸下冲突物；护甲等普通部位没有强制占用逻辑 -> 保留物理部位合法性，不新增“必须穿戴完整套装”的要求。

# 调研记录

- [重复高难语义] -> 第五槽显示“高难”，物品显示“高难应急护盾”，日志与商城仍有“高难槽” -> 槽位统一为“配件”，物品统一为“应急护盾”，难度只负责解锁与数值。
- [旧存档兼容] -> `emergencyShield` 目前持久化为 `outerwear` 且旧名称会直接保留 -> 继续使用稳定 ID，在归一化时迁移为 `accessory` 并刷新显示名称。
- [替换路径] -> `equipToSlot()` 在发现无冲突空位时立即自动穿戴，只有没有空位才显示替换选择 -> 改为始终显示全部合法位置，由玩家决定替换或使用空位。
- [冲突边界] -> 槽位允许为空，`buildEquipAction()` 只在手持组合上自动卸下冲突物；护甲等普通部位没有强制占用逻辑 -> 保留物理部位合法性，不新增“必须穿戴完整套装”的要求。
- [集成复审修正] -> 子任务仅让空位进入手动选择，但前四槽仍固定为头部/身体/主手/副手，实质上仍为护甲预留身体槽 -> 前四槽改为通用装备位，头部/身体/手持部位通过全局冲突规则限制；配件与购买槽继续独立。
- [通用槽冲突] -> 头部和身体各最多 1 件；单手武器最多 2 件；盾与单手武器合计最多 2 件；双手武器最多 1 件且排斥所有其他手持装备 -> 选择新装备时只移除目标槽和真正冲突的旧装备，不要求保留护甲。
- [浏览器配件实显] -> 难度 6 开局 HUD 显示“配件 · 应急护盾”，进战日志显示“【应急护盾】”，未再出现“高难 · 高难应急护盾” -> 配件语义生效。
- [浏览器替换实显] -> 难度 6 首战掉落双手长弓，替换弹窗同时提供装备 1–4；选择装备 2 后实际卸下布衣、短剑和护臂，HUD 仅保留头巾、长弓、两个空位 -> 护甲不再是必穿位置，双手冲突正确清理。

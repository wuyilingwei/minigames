# 调研记录

- [自动流程] -> 当前倒计时结束后复用 `chooseLoot()`，因此仍会进入空槽装备确认或满槽替换界面 -> 自动路径需要一次性完成选择、推荐槽位替换、属性刷新与 `afterEquip()` 收尾。
- [手动流程] -> 玩家手动选择装备仍需要确认和反悔能力 -> 新逻辑只应用于倒计时触发，不改变现有手动选择路径。
- [复选框范围] -> 游戏设置和战利品自动选择都使用 `.toggle input[type="checkbox"]` -> 以这一全局选择器统一表现，并为减少动画类和系统减少动态效果偏好提供静态回退。
- [可访问性修正] -> 首轮浏览器快照把伪元素文字“✓”暴露为未勾选状态的额外文本 -> 改用空内容配合 CSS 边框绘制勾形，保留动画且不污染辅助技术读取。
- [满槽实测] -> 自动战斗在装备栏四槽已满后继续触发战利品 -> 推荐装备直接替换原槽位，窗口隐藏并进入下一波，没有出现替换或确认界面。

# 调研记录

## 初始状态

- 基线：`93b2d9a`，分支 `codex/legend-balance-and-tiers`。
- 任务范围：仅装备等阶、闪避与初始装备；不修改难度面板、应急盾或职业像素 SVG。

## 结论

- 四档统一为制式 / 精工 / 秘藏 / 神铸；缺省或非法 `affixTier` 在 `normalizeEquipment` 中归一到制式，装备卡始终展示名称。
- 职业基础闪避采用 12% / 14% / 16% / 42%（战士 / 天使 / 勇者 / 隐士），保留隐士的明显最高定位；难度 10 第一波追踪约 12% 时前三职业仍分别保留约 0% / 2% / 4% 有效闪避，且不被装备贡献抵消。
- 随机装备闪避由 0%~8% 改为 3%~10%，再沿用既有波次倍率；专项统计覆盖 10,000 个样本并验证波次 0 与 20 的边界及均值增长。
- 四件初始装备增加小额属性，并在旧存档归一化时按名称补齐，避免旧自动档继续保留全 0 起始装备。

# 调研记录

- [槽位限制] -> 前四槽已通用，但难度额外槽仍只接受 accessory/outerwear，购买槽只接受 purchase -> 所有槽使用同一部位集合，显示名统一为连续“装备 N”。
- [初始差异] -> 难度 6 通过 `initSlots()` 加入护盾，购买装备则由 `syncSlotCapacity()` 每次同步强制塞回 -> 护盾和护符都只在新征途初始化时加入；购买当下允许即时装备，之后替换不自动回填。
- [职业护符部位] -> `jobAmulet` 仍被归类为 purchase -> 迁移成普通 accessory，购买只表示获得来源，不再表示专属穿戴部位。
- [护盾命名] -> 稳定 ID 为 `emergencyShield`，用户可见名称已从高难应急护盾改成应急护盾 -> ID 保持兼容，所有新建、归一化、日志和规则文案统一显示“战术护盾”。
- [实际替换] -> 难度 6 且商城装备位已解锁时，双手大剑的替换对话框显示装备 1–6 六个合法位置 -> 装备至第 5 格后战术护盾被替换，原单手剑和副手按冲突规则卸下，第 6 格职业护符保留。

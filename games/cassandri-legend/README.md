# 卡桑德里传说

浏览器文字冒险 RPG。当前发布版为《卡桑德里传说》8.0，采用无需打包器的纯静态资源结构。

在线游玩：<https://minigames.wuyilingwei.workers.dev/games/cassandri-legend/>

入口由 [`index.html`](index.html)、[`styles.css`](styles.css) 和 [`game.js`](game.js) 组成。三者使用相对路径加载，直接用浏览器打开 `index.html` 即可运行；经典脚本会保留现有内联 `onclick` 与全局函数兼容性。

## 更新原则

用户提供的 7.0 单文件仅作为玩法、数值与文案参考；运行入口仍为 [`index.html`](index.html)，以增量兼容方式保留本站现有界面。

- 4 种职业 × 4 种祝福 × 20 波随机战斗
- 随机装备、元素套装、装备与敌人特性
- 能量必杀、防御、自动战斗和最终决战快速模拟
- 金币商城、永久强化、第五装备槽与难度系统
- 自动存档与 3 个手动存档槽，可恢复战斗或战利品选择
- 经典回合制战斗场景与动态生命/护盾条
- 战利品装备对比：按下一名敌人的预测强度估算输出与生存压力，以三角等级显示变化幅度并自动推荐两件掉落中的更优项

## 8.0 版本

1. 在现有界面上增量整合 8.0：保留门户导航、移动端布局、弹窗、难度面板和战利品预测
2. 新增元素套装、敌人特性、自动战斗、能量必杀技与最终决战快速模拟
3. 新增金币商城、潘多拉之盒、永久强化和第五装备槽
4. 新增它之血珠难度机制；高难度会加强敌人并施加额外限制
5. 永久成长继续使用 `kasandri6_save`；战局使用自动槽和 3 个手动槽。6.5 单词条装备会在读取时迁移为 7.0 多词条结构，失装和魔王震落确认也可恢复
6. 保留交互界面；战斗区固定在底部，以原创经典回合制构图显示敌上我下的血条、护盾和即时反馈
7. 商城、存档、设置与装备选择均使用像素风弹窗；确认装备后弹窗会关闭，已完成事件会收束为可展开的终端记录
8. 掉落装备会按下一名敌人的预测强度估算输出和生存压力；两件掉落自动标出优先选择，满槽时高亮推荐替换位置并保留各槽装备详情与变化，且可暂时收起后从右侧面板继续选择
9. 元素套装详情以弹窗展示当前件数、已激活效果与下一档所需件数
10. 新增 36 种可叠加装备特性、三类护盾、追踪/闪避/护甲、多段攻击、智能自动战斗和难度 10 BOSS 特性
11. 高难恢复按难度衰减，胜利金币效率每级提高 10%；难度 3/6/9 解锁额外装备效果与词条，难度 6 后增加装备容量；装备部位与双手/单手互斥规则保持在运行时统一裁决
12. 四色共鸣提供可见的 12% 防御减伤、自然临时战斗盾恢复和生命恢复，并让其他元素套装效果提高 50%；斗篷等附加穿戴可与身体护甲共存，每名敌人拥有稳定的差异像素头像
13. 它之血珠上限为 10；本地作弊模式可临时调整成长和商城道具，退出后恢复进入前的数据

## 运行

无需安装依赖。直接用浏览器打开 [`index.html`](index.html) 即可游玩；仓库根目录执行 `npm run build` 会将三个入口资源一并复制到 `dist/games/cassandri-legend/`。

旧存档仍使用 `kasandri6_save` 永久档案键，并在读取时补齐 8.0 字段；自动档和三个手动槽继续保持兼容。
